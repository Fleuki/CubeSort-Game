# Кубоград

Головоломка-сортировка кубиков для Яндекс Игр и Playgama.
Собери столбик из кубиков одного цвета — на макете города вырастет дом.

Правила игры, арт и тайминги — в [`cubesort-design-doc.md`](cubesort-design-doc.md).
Правила разработки — в [`CLAUDE.md`](CLAUDE.md).

## Запуск

Зависимостей нет: чистый JavaScript, ES-модули, один Canvas.

```
npx http-server -p 8080 .      # или python3 -m http.server 8080
```

и открыть `http://localhost:8080/`.

Шага сборки нет: сервер нужен только потому, что браузеры блокируют
ES-модули по протоколу `file://`. Для просмотра двойным кликом есть
однофайловая сборка `dist/game.html` — режим предпросмотра, не продакшен-путь.

## Проверка на телефоне

Ветка `claude/demo-and-testing-42q0ne` — дефолтная, репозиторий публичный,
поэтому GitHub Pages раздаёт игру прямо из корня:
<https://fleuki.github.io/CubeSort-Game/>

Включается один раз: Settings → Pages → Source: «Deploy from a branch»,
ветка — дефолтная, папка — `/ (root)`. Дальше каждый push обновляет
страницу сам. `.nojekyll` в корне отключает обработку Jekyll: сайт
выкладывается как есть.

Страница отдаётся с `Cache-Control: max-age=600`, так что после пуша
телефон может минут десять показывать старую версию — помогает
перезагрузка с очисткой или `?v=2` в конце ссылки.

## Скрипты

```
node tools/gen-levels.js              # перегенерировать levels/levels.json и levels.js
node tools/gen-levels.js --check 1000 # проверить решаемость 1000 уровней
node tools/build-single.js            # собрать dist/game.html
```

Игре скрипты не нужны — она работает на том, что уже лежит в репозитории.

## Структура

```
index.html            разметка и HUD
style.css             стили оверлея, локальные шрифты
assets/fonts/         woff2-сабсеты Unbounded и Onest (кириллица + латиница)
levels/levels.json    60 предгенерированных уровней
levels/levels.js      те же уровни модулем (fetch по file:// недоступен)
tools/                офлайн-скрипты, в игру не входят
src/game/             правила, генератор, солвер, undo — без DOM и Canvas
src/render/           изометрия, сцена, макет города, раскладка
src/anim/             твины и частицы
src/audio/            синтез звука через WebAudio
src/ui/               DOM-оверлей: HUD, экраны, оверлей отладки
src/platform/         фасад площадок: Яндекс, Playgama, заглушка
```

## Что сделано

- 60 уровней, обратная генерация, гарантированная решаемость;
- `par` — оптимальное число ходов (IDA* по нормализованному состоянию,
  потолок глубины 20); если оптимум за потолком, уровень помечается
  `"parExact": false`, а par берётся как 0.8 длины обратного пути;
- групповое перемещение, подсказка (BFS), отмена, +1 столбик,
  «Заново» — в меню под шестерёнкой;
- растущий макет города: дома, башни, деревья, фонари, мост по районам;
- анимации и тайминги из раздела 6 дизайн-дока, частицы, тряска камеры;
- синтезированный звук с пентатоникой при укладке подряд;
- сохранения через фасад площадки, `prefers-reduced-motion`, пауза по потере фокуса;
- оверлей отладки для проверки с телефона: тройной тап по номеру уровня
  показывает fps, границы зон, размер кубика, вьюпорт, уровень и par.
  Весь код — в `src/ui/debug.js`, вырезается одной строкой в `main.js`.
