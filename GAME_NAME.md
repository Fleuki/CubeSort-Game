# Каноническое название игры

Единственный источник правды по названию. Гайд §5.1.3 / §5.12:
название обязано совпадать **побуквенно** во всех полях черновика и во
всех материалах. Самая частая причина отказа по материалам — расхождение
названия хотя бы в одном месте.

```
Каноническое название: Кубоград
Написание: с заглавной первой буквы, остальные строчные, БЕЗ КАПСА
Международное написание: Kubograd (транслитерация, не перевод)
```

## Две локали, одно слово

Правило побуквенного совпадения (§5.1.3 / §5.12) действует **внутри локали**:

- **Русская локаль и все материалы Яндекс.Игр** — строго `Кубоград`.
  Здесь никаких вариантов нет.
- **Международные площадки (Playgama)** — `Kubograd`. Это транслитерация
  того же слова, а не другое название: латиницей записана та же «Кубоград».

Внутри каждой локали название обязано совпадать побуквенно везде: `<title>`,
`apple-mobile-web-app-title`, логотип на сплэше и в меню, поля черновика.
За это отвечает ключ `app.title` в `src/i18n.js` — другого места, где
название пишется буквами, в коде нет.

## Запрещённые варианты

- `КУБОГРАД` — капс запрещён (§5.1.3)
- `кубоград` — со строчной
- `Кубики`, `Кубо Град`, `Кубо-град` — рабочие варианты, в публикацию не идут
- `Cubograd`, `CubeSort`, `Cube City` и любые другие переводы-синонимы —
  запрещены и в английской локали тоже: там допустима **только**
  транслитерация `Kubograd`
- любые подзаголовки в одном месте и без них в другом
  (`Кубоград: сортировка` ≠ `Кубоград`) — выбран вариант **без** подзаголовка

## Где название обязано совпадать (чек-лист §5)

- [x] `<title>` страницы — ключ `app.title`, ставится из `src/main.js`
- [x] `apple-mobile-web-app-title` — тот же ключ, меняется вместе с языком
- [x] Заголовок в меню и на сплэше загрузки (`.logo`) — `data-i18n="app.title"`
- [ ] Поле «Название» черновика (консоль)
- [ ] «Описание для SEO» (консоль) — ⚠️ частый отказ, проверить
- [ ] «Об игре» / «Короткое описание» / «Как играть» (консоль)
- [x] Иконка 512×512 — `store/icon-512.png` (без текста)
- [x] Обложка 800×470 — `store/cover-800x470.png` («Кубоград» шрифтом Unbounded)
- [ ] Скриншоты
- [ ] Вертикальное и горизонтальное промо-видео
- [ ] Рекламные видео

Название зафиксировано **до** генерации иконки, обложки и рендера видео.
Менять его после — значит перерисовывать все материалы заново.
