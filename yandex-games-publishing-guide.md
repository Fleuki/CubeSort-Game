# Публикация игры на Яндекс Играх — рабочий справочник

> Файл-инструкция для ИИ-ассистента и для себя. При разработке новой игры — сверяться с ним ДО отправки на модерацию.
> Источник: интерфейс консоли разработчика games.yandex.ru + реальные замечания модерации.
> Версия 2 — учтены отказы по играм «Грибной Сумрак», «Лесорубы», «Бездна».

---

## 0. Контекст разработчика

- Игры делаются с помощью нейросетей (HTML5 / JS), Canvas, без сборщиков.
- В черновике есть блок «Использование ИИ при создании игры» — выбирать честно:
  - Игра полностью создана с помощью ИИ-инструментов
  - ИИ использовался частично (отдельные ассеты, код или тексты)
  - ИИ не использовался
- Игры делаются **только на русском** → в поле «Игра переведена на» указывать **только Русский**, английскую вкладку в описании не добавлять.

### 0.1. ⚠️ НОВОЕ ПРАВИЛО МОДЕРАЦИИ (блокирует отправку)

> «Теперь для отправки игры нужен действующий договор по Единой лицензионной схеме или договор участия в РСЯ. Без одного из этих договоров отправить игру на модерацию не получится. Если действующего договора пока нет, заполните второй этап анкеты РСЯ и дождитесь завершения проверки документов.»

**Действие до всего остального:** консоль → «Заполнить анкету» → второй этап анкеты РСЯ → дождаться проверки документов. Без этого любые фиксы бессмысленны — черновик не уйдёт на модерацию.

### 4.3. Звук только через Web Audio API (§ 1.6.1.6, § 1.6.2.5) — ОБЯЗАТЕЛЬНО

**Правило: в проекте не должно быть ни одного тега `<audio>` и `<video>`.** Именно они поднимают системный плеер на десктопе и карточку в шторке уведомлений на Android/iOS.

```js
const AudioCtx = window.AudioContext || window.webkitAudioContext;
const actx = new AudioCtx();
const masterGain = actx.createGain();
masterGain.connect(actx.destination);

// разблокировка контекста первым же пользовательским жестом
function unlockAudio() {
  if (actx.state === 'suspended') actx.resume();
  window.removeEventListener('pointerdown', unlockAudio);
}
window.addEventListener('pointerdown', unlockAudio);

// загрузка сэмпла
async function loadSound(url) {
  const buf = await fetch(url).then(r => r.arrayBuffer());
  return await actx.decodeAudioData(buf);
}

function playSound(buffer, { loop = false, volume = 1 } = {}) {
  const src = actx.createBufferSource();
  const g = actx.createGain();
  g.gain.value = volume;
  src.buffer = buffer;
  src.loop = loop;
  src.connect(g).connect(masterGain);
  src.start(0);
  return src;
}
```

Дополнительно:
- `navigator.mediaSession` **не использовать** вообще.
- Если музыка нужна — это тоже `AudioBufferSourceNode` с `loop = true`, а не `<audio loop>`.
- Синтезированный звук через осцилляторы — самый безопасный вариант (нет ассетов, нет лицензий, нет плеера).

**Само-проверка перед отправкой:**
```js
console.assert(document.querySelectorAll('audio, video').length === 0, 'Найден медиа-элемент!');
```

### 4.5. SDK, язык и Game Ready API (§ 2.14, § 1.19) — СТРОГИЙ ПОРЯДОК

Главная ошибка из отказа: игра уже интерактивна, а `ready()` вызывается позже. Порядок должен быть такой:

```html
<script src="https://yandex.ru/games/sdk/v2"></script>
```

```js
let ysdk = null;
let inputEnabled = false;   // ввод заблокирован до ready()

async function boot() {
  // 1. SDK
  ysdk = await YaGames.init();

  // 2. Язык — СРАЗУ, до отрисовки любого UI (§ 2.14)
  const lang = ysdk.environment.i18n.lang;   // 'ru' | 'en' | 'tr' ...
  applyLanguage(lang);

  // 3. Загрузка ассетов, декод звука, генерация уровней
  await loadAllAssets();

  // 4. Игра ГОТОВА — сообщаем платформе (§ 1.19)
  await ysdk.features.LoadingAPI?.ready();

  // 5. Только теперь показываем меню и включаем ввод
  inputEnabled = true;
  showMainMenu();
}

boot().catch(console.error);
```

Жизненный цикл GRA дальше:

```js
function onGameplayStart() { ysdk.features.GameplayAPI?.start(); } // старт уровня, снятие с паузы
function onGameplayStop()  { ysdk.features.GameplayAPI?.stop();  } // пауза, меню, конец уровня, реклама, потеря фокуса
```

Правила:
- `ready()` — **ровно один раз**, до того как игрок сможет что-то нажать.
- Никакого интерактивного экрана (меню, кнопка «Играть») до `ready()`.
- `start()` — только когда идёт активный геймплей, `stop()` — при любой паузе, включая `visibilitychange`.
- Проверять в дебаг-панели черновика: события GRA должны приходить в правильном порядке.

## 5. ПРАВИЛО ОДНОГО НАЗВАНИЯ (§ 5.1.3)

Самая частая причина отказа по материалам. Заводить в проекте файл `GAME_NAME.md`:

```
Каноническое название: Грибной Сумрак
Написание: с заглавных букв каждого слова, БЕЗ КАПСА
Запрещённые варианты: ГРИБНОЙ СУМРАК, Грибной сумрак, Mushroom Dusk, рабочие названия
```

Название обязано совпадать **побуквенно** в:
1. заголовке внутри игры (главное меню, сплэш);
2. `<title>` страницы;
3. поле «Название» черновика;
4. поле «Описание для SEO»;
5. поле «Об игре» / «Короткое описание» / «Как играть»;
6. иконке 512×512;
7. обложке 800×470;
8. скриншотах;
9. вертикальном и горизонтальном промо-видео;
10. рекламных видео.

Правила написания:
- **Капс запрещён** — «Бездна», а не «БЕЗДНА».
- Никаких подзаголовков в одном месте и отсутствия их в другом («Лесорубы» ≠ «Лесорубы: дуэль на одном экране» — выбрать один вариант и использовать везде).
- Название фиксируется **до** генерации обложки, иконки и рендера видео.

## 6. ПРАВИЛА ДЛЯ МЕДИАМАТЕРИАЛОВ (§ 8.3.1)

- Скриншоты и видео — **только из финальной сборки**, той самой, что уходит на модерацию.
- Нельзя: концепт-арт, нейросетевые иллюстрации, изображения «по мотивам», кадры из прототипа.
- Нельзя: артефакты сжатия, избыточное затемнение, полностью одноцветные кадры.
- Каждый скриншот должен показывать узнаваемый игровой экран с UI.
- Десктопные скриншоты снимать в десктопном разрешении, мобильные — в мобильном (не растягивать одно в другое).
- Промо-видео перерендерить, если менялось название или визуал.

1. Проверить, что договор (ЕЛС или РСЯ) активен — иначе отправка заблокирована.
2. Зафиксировать **одно** название в `GAME_NAME.md`, без капса.
3. Прогнать код по разделу 4: скролл, контекстное меню, Web Audio, масштаб, SDK, GRA.
4. Убедиться, что в проекте нет `<audio>` и `<video>` (`grep -r "<audio\|<video" .`).
5. Проверить порядок GRA: `ready()` до появления интерактивного меню.
6. Запустить игру **в режиме черновика** и проверить консоль на JS-ошибки.
7. Тест на десктопе: правый клик, выделение, колесо мыши (нет скролла), нет системного плеера.
8. Тест на телефоне: долгий тап, протяжка пальцем (нет скролла и pull-to-refresh), нет карточки в шторке уведомлений.
9. Сделать скриншоты и видео **из этой же сборки**.
10. Нарисовать иконку 512×512 и обложку 800×470 с каноническим названием.
11. Заполнить черновик, затем пройтись по всем текстовым полям и сверить название.
12. Пройти чеклист из раздела 1.
13. Отметить использование ИИ.
14. Отправить на модерацию.

## 8. ПАМЯТКА: частые причины отказа

**Технические**
- Есть `<audio>` / `<video>` → системный плеер на десктопе и в шторке на мобильных.
- `LoadingAPI.ready()` вызывается после того, как игра стала интерактивной.
- Язык не берётся из `ysdk.environment.i18n.lang` или применяется поздно.
- Страница скроллится (особенно инерция на iOS и pull-to-refresh).
- Контекстное меню / выделение текста не отключены.
- UI обрезается на нестандартных экранах.
- Реклама в середине геймплея; rewarded без явного согласия.

**По материалам**
- Название не совпадает хотя бы в одном поле — включая SEO-описание и промо-видео.
- Название капсом.
- Другое название на обложке.
- Скриншоты не из игры (арт вместо геймплея) — «вводит пользователя в заблуждение».
- Заявлен язык, который в игре не реализован.
