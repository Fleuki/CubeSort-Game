# Источники звука

Все файлы — **CC0 / Public Domain**. Лицензия проверяется у каждого файла
отдельно: рядом с CC0 на тех же площадках лежат CC-BY и CC-BY-NC, их брать
нельзя.

CC0 не требует указания авторства, но этот файл нужен для другого: если
модерация спросит о происхождении звука, ответ должен занимать минуту,
а не вечер раскопок.

## Формат

| | Эффекты | Музыка |
|---|---|---|
| Формат | WAV, моно, 44.1 кГц, 16 бит | MP3, 44.1 кГц, 96–112 kbps CBR |
| Где лежит | `assets/audio/sfx/` | `assets/audio/music/` |
| Нормализация | до −3 dBFS, тишина по краям обрезана | — |

MP3 для коротких эффектов не подходит: кодек добавляет тишину в начало файла,
и на щелчке в 60 мс эта задержка слышна.

## Не из файлов

`playPlace()` — укладка кубиков — остаётся процедурным синтезом в
`src/audio/sfx.js`: ноты идут вверх по пентатонике при укладке подряд, и
семплами эту связку не собрать без шести отдельных файлов одного инструмента.
Это собственный код, не заимствование.
