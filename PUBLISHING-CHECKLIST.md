# Чек-лист публикации «Кубоград» на Яндекс Играх

Рабочий трекер под гайд `yandex-games-publishing-guide.md`. Отмечай по мере
готовности. Разделено на **код** (сделано в репозитории) и **консоль/материалы**
(делаешь ты руками в кабинете разработчика и в графике).

> **Версия дизайна:** публикуется НОВЫЙ дизайн (крышка на собранном столбике,
> видимая вместимость, три режима сложности — «Итерации 6–12»). Правки
> публикации перенесены на него; все скриншоты и видео сняты с него.
> Игровой код взят из ветки `new-session-8f2qg2` и объединён с правками
> публикации в `game-publication-prep-9a6v0g` — заливать в Яндекс нужно
> сборку именно из `game-publication-prep-9a6v0g`.

## A. Код и техническое качество — сделано в этой сборке

- [x] **Название везде каноническое** — `<title>`, meta, меню, сплэш = «Кубоград»
      (см. `GAME_NAME.md`). Зафиксировано до генерации материалов.
- [x] **Ноль тегов `<audio>` / `<video>`** — весь звук через Web Audio API
      (`src/audio/sfx.js`). Проверено: `document.querySelectorAll('audio,video').length === 0`.
      Значит нет системного плеера на десктопе (§1.6.2.5) и карточки в шторке
      уведомлений на мобильных (§1.6.1.6). `navigator.mediaSession` не используется.
- [x] **Браузерная прокрутка убита** (§1.10.2) — `html, body { position: fixed; inset: 0 }`
      в `style.css`; перехват `touchmove`, `wheel` и «скроллящих» клавиш в `src/main.js`.
      Гасит инерционный скролл iOS и pull-to-refresh.
- [x] **Контекстное меню и выделение отключены** (§1.6) — `contextmenu`, `selectstart`,
      `dragstart`, `gesturestart`, `dblclick` перехвачены; `user-select: none` в CSS.
- [x] **Пауза звука при потере фокуса** (§1.3) — `visibilitychange` + `blur`/`focus`,
      `AudioContext.suspend()`, реклама глушит звук на время ролика.
- [x] **Порядок Game Ready API** (§1.19) — `init → загрузка ассетов → ready() → меню и ввод`
      в `boot()` (`src/main.js`). `LoadingAPI.ready()` вызывается ровно один раз,
      до первого интерактивного экрана. Ввод до `ready()` заблокирован.
- [x] **GameplayAPI.start()/stop()** (§1.19.2) — старт при входе в уровень,
      stop при меню, победе, рекламе, потере фокуса.
- [x] **Реклама только в паузах геймплея** (§4.4) — интерстишл только между
      уровнями, не чаще раза в 3 минуты и не раньше 3-го уровня; не показывается
      во время анимаций и сразу после проигрыша (проигрыша в игре нет).
- [x] **Rewarded — по явному нажатию игрока** (§4.5) — только кнопки «Отменить»
      (после 3 бесплатных), «Подсказка» (после 2), «+1 столбик».
- [x] **Сохранение прогресса** (§1.9) — через фасад `src/platform/`: облако Яндекса
      (`player.setData`) с фоллбэком на `localStorage`. Уровень, город, настройки.
- [x] **Масштабирование без обрезки** (§1.10) — canvas по `min(scaleX, scaleY)`,
      `window.innerHeight`, `devicePixelRatio` ≤ 2, `viewport-fit=cover`.
- [x] **Портретная рамка на десктопе** (§1.10) — на широком экране сцена сжимается
      до вертикальной области и центрируется (иначе изометрия города расползалась
      в полосу), HUD привязан к рамке. Проверено на 1280×800 и 1920×1080.
- [x] **Консоль чистая** (§1.14) — 0 JS-ошибок, 0 предупреждений, 0 внешних
      запросов, 0 медиа-элементов (проверено headless-браузером на 390×844).
- [x] **Фавикон инлайновый** — нет 404 за `favicon.ico` в консоли.
- [x] **Только русский** — системы локализации нет, английских строк в UI нет.
      В поле «Игра переведена на» указывать **только Русский**.
- [x] **Автоопределение языка через SDK** (§2.14) — `ysdk.environment.i18n.lang`
      читается сразу после `YaGames.init()` (`src/platform/yandex.js`), применяется
      в `applyLanguage()` до первого показа UI (`src/main.js`). Playgama — симметрично
      через `bridge.platform.language`. Модерация требует сам факт чтения языка из
      SDK до интерактивности даже для одноязычной игры; переводов в игре нет,
      поддержан только русский.

## A2. Playgama — обязательное к публикации

- [x] **Мост подключён** — `https://bridge.playgama.com/v2/stable/playgama-bridge.js`
      в `<head>` `index.html`, конфиг `playgama-bridge-config.json` рядом с ним.
- [x] **Storage через мост** — `bridge.storage.get([...])` / `set([...], [...])`,
      локальное зеркало только как страховка от отката прогресса.
- [x] **Interstitial и rewarded** — через `bridge.EVENT_NAME.*`, награда только
      по состоянию `rewarded`.
- [x] **`platform.isAudioEnabled` + `AUDIO_STATE_CHANGED`** — площадка может
      потребовать тишины, игра её слушает.
- [ ] **`PAUSE_STATE_CHANGED` — НЕ СДЕЛАНО, блокирует публикацию.**
      Дока Playgama помечает обработку паузы как Required: по `isPaused === true`
      игра обязана остановить геймплей, таймеры и звук, по `false` — продолжить.
      Это правка игрового цикла в `src/main.js`, вынесена в отдельную задачу.
      **Не отправлять сборку на Playgama, пока не закрыто.**
- [ ] **Проверка на реальной площадке** — mock-окружение не проверяет ни рекламу,
      ни облачные сохранения. Нужен прогон в кабинете Playgama.

- [ ] Описание для SEO: проверить название = `Кубоград` ⚠️ частый отказ
- [ ] Об игре: проверить название
- [ ] Короткое описание (≤70 симв.): проверить название

## C. Перед самой отправкой (§7)

1. [ ] Договор активен.
2. [ ] Прогнать игру **в режиме черновика**, проверить консоль — нет JS-ошибок.
3. [ ] Десктоп: правый клик, выделение, колесо мыши (нет скролла), нет системного плеера.
4. [ ] Телефон: долгий тап, протяжка пальцем (нет скролла и pull-to-refresh),
       нет карточки медиаплеера в шторке уведомлений.
5. [ ] Пройтись по всем текстовым полям и сверить название побуквенно (`GAME_NAME.md`).
6. [ ] Скриншоты/видео сняты из этой же сборки.
7. [ ] Повысить версию сборки, залить, отправить на модерацию.
